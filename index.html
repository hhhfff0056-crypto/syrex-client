Вопросы
и ответы.

Когда можно будет скачать Syrex?

Публичная дата выхода пока не заявлена. Когда появится проверенная сборка, информация будет размещена на сайте.

Где зарегистрировать аккаунт?

Форма регистрации пока не подключена. Статическая страница на GitHub Pages не предоставляет безопасную систему пользователей сама по себе.

Для какой версии Minecraft будет клиент?

Поддерживаемые версии и системные требования будут опубликованы вместе с релизом.
