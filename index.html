03 / FAQ

Частые вопросы.

Можно ли скачать клиент сейчас?

Пока нет. Файл клиента не добавлен, поэтому кнопка показывает уведомление вместо нерабочей загрузки.

Есть ли регистрация и личный кабинет?

Сейчас показан только внешний вид сайта. Реальная регистрация требует защищённого сервера или провайдера авторизации; GitHub Pages сам по себе этого не предоставляет.

С какими версиями Minecraft работает Syrex?

Совместимость будет указана после публикации проверенной сборки.
